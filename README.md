# AI Evals — Interactive Notes

An interactive, single-page study guide for AI evaluation: from vibes to evidence.

**Covers:** what an eval is, core vocabulary, end-to-end vs component evals, the 9-step design loop, case design, graders and metrics, LLM-as-judge (biases and validation), statistics (pass@k, pass^k, confidence intervals), debugging (first divergence, oracle probes), failure patterns, choosing fixes, the eval flywheel, plus interview extras (RAG and agent metrics, Goodhart's law, online evaluation).

**Includes:** 30+ interactive widgets, a searchable glossary, flashcards, and an interview quiz.

## Run locally
Open `index.html` in a browser. No build step.

## Deploy
Enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
